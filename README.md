# 出海达人匹配助手 · Demo

在线体验：https://z2302743489.github.io/influencer-match-demo/

一个 AI 达人营销的完整闭环 Demo：品牌说一句话需求 → 结构化需求卡 → 匹配排序（附推荐理由）→ 人工审核 → 个性化英文邀约 → 读回复与谈价签约 → 拍摄要点与寄样 → 内容审核（#ad 标注、禁用说法、竞品、卖点）→ 效果复盘（CPM / CPE / ROI）→ 结果写回达人档案，影响下一次排序。

## 功能

- **两种数据**
  - 示例数据：虚构的达人和品牌，不联网也能演示
  - YouTube 实时数据：通过 YouTube Data API v3 搜索真实频道，读取频道资料、近期视频、热门评论和目标市场热门榜
- **两种模式**
  - 规则模式：关键词和正则解析需求，固定权重打分，模板生成邮件
  - AI 模式：需求解析、排序理由和邀约邮件交给 DeepSeek 生成，失败时自动用规则结果兜底
- **三个人工接管点**：确认需求、选择达人、发送邀约，都必须由人确认
- **规则兜底**：硬条件筛选、风险标签、粉丝水分评估、邮件数字校验都由规则完成，结果确定、可解释
- **粉丝水分评估**：用播放 / 订阅、互动率、评论质量、评论 / 点赞、播放稳定性、频道年龄 6 个公开信号估算风险，只作提示，不是结论
- **达人授权（演示）**：模拟达人通过平台官方授权分享真实受众数据的流程，授权后用“已认证”数据代替推测；页面和数据都标明是模拟
- 演示进度自动保存在浏览器里，刷新后回到原来那一步

## 使用

1. 打开在线地址
2. 用 YouTube 实时数据：在第 1 步填自己的 YouTube Data API Key
3. 用 AI 模式：在第 1 步填自己的 DeepSeek API Key，点“测试连接”

Key 只保存在当前浏览器的本地存储里，不会上传到这个仓库或任何其他服务器；页面会直接用它调用 YouTube 和 DeepSeek 的官方接口。

## 说明

- 示例数据中的达人和品牌均为虚构。
- 公开接口拿不到受众画像（国家、年龄、性别），页面用频道国家和评论语言间接推测，并标明是推测。
- 邀约发送是模拟的，不会真的发出邮件。
- 本 Demo 用 AI Coding 工具开发，产品逻辑、流程和规则由作者设计。
